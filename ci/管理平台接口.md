# 管理平台接口文档

> 本文档描述「管理平台」（前端 Vue 后台，产物 `webroot/`，仅 `admin_local` 管理员可见）调用的后端接口，与 `接口文档.md`（客户端/安卓接口）互补。
>
> **通用约定**
> - 基础路径：后端服务地址（默认 `http://<host>:8081`）。
> - 响应统一结构：`{ "message": "操作成功", "status": 200, "data": ... }`。
> - **鉴权**：本文档所有 `/admin/**` 接口以及 `PUT /config/ldap` 均需在**请求头**携带 `token`（值为登录返回的令牌，**非** `Authorization: Bearer` 形式）。未携带或无效令牌返回 401；非 admin 角色返回 403。
> - 错误响应：`{ "message": "错误信息", "status": <错误码>, "data": null }`。

## 一、部门管理

### 1. 部门列表

**接口地址**: `/admin/depts`

**请求方式**: `GET`

**请求头**:

| 参数名 | 类型   | 必填 | 说明         |
| ------ | ------ | ---- | ------------ |
| token  | String | 是   | 登录返回的令牌 |

**请求参数**: 无

**响应示例**:

```json
{
  "message": "操作成功",
  "status": 200,
  "data": [
    { "id": 1, "name": "武汉绿网", "parentId": null, "path": "OU=武汉绿网,DC=greenet,DC=com,DC=cn", "source": "LDAP" },
    { "id": 2, "name": "研发中心", "parentId": 1, "path": "OU=研发中心,OU=武汉绿网,DC=greenet,DC=com,DC=cn", "source": "LOCAL" }
  ]
}
```

**响应字段说明**:

| 字段     | 类型   | 说明                                          |
| -------- | ------ | --------------------------------------------- |
| id       | Long   | 部门 ID                                       |
| name     | String | 部门名称                                      |
| parentId | Long   | 上级部门 ID（根部门为 null）                   |
| path     | String | LDAP 风格 DN（LOCAL 部门也以 DN 风格存储）     |
| source   | String | 来源：`LDAP` / `LOCAL`                        |

**错误码**:

| 状态码 | 说明           |
| ------ | -------------- |
| 401    | 未登录或登录过期 |
| 403    | 无管理员权限   |

### 4. 删除部门

**接口地址**: `/admin/depts/{id}`

**请求方式**: `DELETE`

**请求头**:

| 参数名 | 类型   | 必填 | 说明         |
| ------ | ------ | ---- | ------------ |
| token  | String | 是   | 登录返回的令牌 |

**请求参数**: 无（部门 ID 在路径中）

**响应示例**:

```json
{
  "message": "操作成功",
  "status": 200,
  "data": "删除成功"
}
```

**业务说明**:

- 删除部门会级联清理该部门的文档授权与可见范围绑定。
- 若该部门存在子部门或仍被设为可见范围，后端会拒绝删除并返回 400。

**错误码**:

| 状态码 | 说明                         |
| ------ | ---------------------------- |
| 400    | 该部门存在子项/引用，无法删除 |
| 401    | 未登录或登录过期             |
| 403    | 无管理员权限                 |

| 字段        | 类型           | 说明                                     |
| ----------- | -------------- | ---------------------------------------- |
| list        | Array[UserPageVo] | 当前页用户列表                        |
| total       | Long           | 总记录数                                 |
| page        | int            | 当前页码                                 |
| size        | int            | 每页条数                                 |
| id          | Long           | 用户 ID                                  |
| account     | String         | 登录账号                                 |
| name        | String         | 姓名                                     |
| deptId      | Long           | 所属部门 ID                              |
| deptName    | String         | 所属部门名称                             |
| source      | String         | 来源：`LDAP` / `LOCAL`                   |
| mustChangePwd | int          | 是否需强制改密（1=是，0=否）             |
| updateTime  | String         | 最近更新时间                             |
| roles       | Array[RoleItem] | 已绑定角色列表 `{id, code, name}`      |

**错误码**:

| 状态码 | 说明                         |
| ------ | ---------------------------- |

### 8. 新建本地用户

**接口地址**: `/admin/users`

**请求方式**: `POST`

**请求头**:

| 参数名 | 类型   | 必填 | 说明         |
| ------ | ------ | ---- | ------------ |
| token  | String | 是   | 登录返回的令牌 |

**请求参数**:

| 参数名           | 类型          | 必填 | 说明                              |
| ---------------- | ------------- | ---- | --------------------------------- |
| account          | String        | 是   | 登录账号                         |
| name             | String        | 是   | 姓名                             |
| password         | String        | 是   | 初始密码（BCrypt 落库）           |
| deptId           | Long          | 否   | 所属部门 ID                       |
| visibleDeptIds   | Array[Long]   | 否   | 用户可见部门范围（按 USER 绑定）  |

**请求示例**:

```json
{
  "account": "lisi",
  "name": "李四",
  "password": "Lisi@123",
  "deptId": 3,
  "visibleDeptIds": [2, 3]
}
```

**响应示例**:

```json
{
  "message": "操作成功",
  "status": 200,
  "data": { "id": 20, "account": "lisi", "name": "李四", "deptId": 3, "source": "LOCAL", "mustChangePwd": 1 }
}
```

**业务说明**:

- 仅可创建 `LOCAL` 来源用户；初始密码以 BCrypt 加密存储，且 `mustChangePwd=1`（首次登录需改密）。
- `visibleDeptIds` 决定用户在组织树中可看到的部门（仅影响可见范围，不等于文档阅读权限）。

**错误码**:

| 状态码 | 说明                         |
| ------ | ---------------------------- |
| 400    | 账号已存在 / 参数错误        |
| 401    | 未登录或登录过期             |
| 403    | 无管理员权限                 |

## 四、可见部门范围（无权限组）

> 命名约定：「部门可见范围」=`visible_dept_rel` 直连（用户在组织树可看到的部门）；「文档授权」=DocShareRel（能否读某文档）。两者**正交**，绑定可见范围不等于文档阅读权限。

### 16. 查询可见部门

### 31. 立即全量同步（异步）

**接口地址**: `/admin/ldap-sync/full`

**请求方式**: `POST`

| 参数名 | 类型   | 必填 | 说明         |
| ------ | ------ | ---- | ------------ |
| token  | String | 是   | 登录返回的令牌 |

**请求参数**: 无

**响应示例（正常触发）**:

```json
{
  "message": "操作成功",
  "status": 200,
  "data": { "status": "STARTED", "message": "已触发全量同步，后台执行中，请稍候刷新查看结果" }
```

**响应示例（已有同步进行中）**:


- 若互斥锁已被占用（手动全量/确认式应用/定时任务正在跑），返回 `BUSY` 提示「当前正在同步，请稍后重试」。
- 后台执行完毕后，可通过「查询同步状态」接口或定时轮询感知完成。

**错误码**:

| 状态码 | 说明           |
| ------ | -------------- |

### 33. 获取 LDAP 配置

### 34. 更新 LDAP 配置

**接口地址**: `/config/ldap`

**请求方式**: `PUT`

**请求头**:

| 参数名 | 类型   | 必填 | 说明         |
| ------ | ------ | ---- | ------------ |
| token  | String | 是   | 登录返回的令牌（需 admin） |

**请求参数**:

| 参数名      | 类型          | 必填 | 说明                                          |
| ----------- | ------------- | ---- | --------------------------------------------- |
| url         | String        | 否   | LDAP 服务器地址                               |
| baseDn      | String        | 否   | 目录根 DN                                     |
| username    | String        | 否   | 绑定账号                                      |
| password    | String        | 否   | 绑定密码（**留空表示不修改现有密码**）         |
| trees       | Array[String] | 否   | 同步根节点列表                                |
| syncTimes   | String        | 否   | 定时全量同步时刻（逗号分隔）                  |
| syncEnabled | Boolean       | 否   | 定时同步总开关                                |

**请求示例**:

```json
{
  "url": "ldap://10.8.5.31:389",
  "baseDn": "DC=greenet,DC=com,DC=cn",
  "username": "admin@greenet.com.cn",
  "password": "",
  "trees": ["OU=武汉绿网,OU=绿色网络,DC=greenet,DC=com,DC=cn"],
  "syncTimes": "10:00,20:00",
  "syncEnabled": true
}
```

**响应示例**:

```json
{
  "message": "操作成功",
  "status": 200,
  "data": "配置更新成功"
}
```

**业务说明**:

- 可只传需要更新的字段（增量更新）。
- `password` 为空字符串表示保留原密码；非空则覆盖。
- 更新后立即生效（自动重新加载配置），无需重启；修改 `syncTimes` 在下一轮调度执行后生效，无需重启。

**错误码**:

| 状态码 | 说明           |
| ------ | -------------- |
| 401    | 未登录或登录过期 |
| 403    | 无管理员权限   |
| 500    | 配置更新失败   |
